Сравнение концептов

Каждый концепт — не просто другой дизайн, а другой подход к взаимодействию.

CONCEPT 01

Immersive Fullscreen

Фото во весь экран, UI поверх. Как Stories.
✓ Максимум визуала
✓ Отлично на телефоне
✗ Меньше контроля
✗ Нужны очень качественные фото
CONCEPT 02

Magazine Layout

Асимметрия, засечки, журнальная типографика.
✓ Уникальный, запомнится
✓ Эффектно в портфолио
✗ Сложнее сделать адаптив
✗ Больше кода
CONCEPT 03

Zen Minimal

Один объект, воздух, спокойствие.
✓ Идеально для малышей (фокус)
✓ Соответствует вашему вкусу
✓ Проще реализовать
✗ Может показаться "пустым"
CONCEPT 04

Deck of Cards

3D стопка, свайп, тактильность.
✓ Весело для ребёнка
✓ Естественные жесты
✗ Не очень "взрослый"
✗ Сложнее на десктопе
CONCEPT 05

Dashboard Grid

Всё видно сразу, клик открывает.
✓ Родитель быстро находит
✓ Можно комбинировать с другими
✗ Нужен отдельный экран для play
✗ Больше кликов
💡 Мой совет для портфолио:

Самые сильные — Concept 03 (Zen Minimal) и Concept 02 (Magazine). Zen идеален по UX для вашей задачи и соответствует референсам (Notion, Untitled). Magazine — вау-эффект для портфолио, но требует больше работы.

Гибридный вариант: основной экран как Zen (03), а в настройках/категориях — переключатель на Grid (05), чтобы быстро находить нужное животное. Это даст и красоту, и функциональность.

Или скажите «Concept X, но с элементом Y из Z» — я соберу финальный микс.

# 🐾 Кто так говорит?

Веб-приложение для родителей, обучающих малышей (1.5–4 года) узнаванию животных.
Крупные фотографии, реалистичные звуки, минимум действий — максимум пользы.

🔗 **Демо:** [kto-tak-govorit.vercel.app](https://kto-tak-govorit.vercel.app)

---

## ✨ Что это такое?

Одностраничное веб-приложение, где ребёнок видит крупное фото животного,
название и слышит его настоящий голос. Родитель листает карточки стрелками
или клавиатурой, нажимает Space — и малыш знакомится с миром.

**Не является игрой.** Интерфейс рассчитан на взрослого, который сидит рядом
с ребёнком за ноутбуком или держит телефон одной рукой.

---

## 🌟 Сценарии использования

| Сценарий | Как это работает |
|---|---|
| 🛋️ **Вечер на диване** | Мама листает карточки на телефоне, малыш смотрит и повторяет «мяу», «гав» |
| 💻 **Папа за ноутбуком** | Включил автоплей — слайд-шоу со звуком, ребёнок смотрит, папа работает |
| ✈️ **Поезд / самолёт** | Приложение работает офлайн после первого визита — интернет не нужен |
| 🤔 **«А как говорит жираф?»** | Открыл раздел «Саванна», свайпнул до жирафа, показал ребёнку |

---

## 🎨 Что внутри

- **55+ животных** с реалистичными фото и звуками из открытых источников
- **7 тематических разделов:** Питомцы, Ферма, Саванна, Лес, Птицы, Море, Насекомые
- **Glass-эффект** в стиле Apple Liquid Glass — полупрозрачные панели с размытием
- **9 акцентных цветов** — пользователь выбирает палитру под себя
- **Светлая и тёмная темы** с автоматическим определением по системе
- **3 вида анимаций** переходов: плавный, простой, без анимации
- **Полное управление с клавиатуры** — стрелки, Space, цифры, горячие клавиши
- **Свайпы** на мобильных устройствах
- **Админ-панель** для добавления новых животных (защищена паролем)

## 🚀 Возможности

| Фича | Описание |
|---|---|
| 🔊 **Несколько вариантов звука** | У каждого животного может быть 1–5 записей. Случайный выбор или все подряд |
| ▶️ **Автоплей** | Звук воспроизводится автоматически при показе карточки |
| 🔁 **Автопереход** | Слайд-шоу с настраиваемым интервалом (3–60 сек) |
| 🔀 **Случайный порядок** | Перемешивание животных внутри категории |
| 🔇 **Mute в один клик** | Кнопка в хедере — мгновенное отключение звука |
| 📱 **Адаптивный дизайн** | От 320px до 2560px — телефон, планшет, ноутбук, 4K |
| ⌨️ **Горячие клавиши** | ← → навигация, Space — звук, M — mute, S — настройки, F — полный экран |
| 🖼️ **Автоконвертация фото** | Загрузили JPG — получили WebP 1920px, −80% веса |
| 💾 **Настройки сохраняются** | localStorage — переживают перезагрузку страницы |
| 🔒 **Приватность** | Никакой аналитики, никаких cookies, никаких данных на сервер |

## 🛠 Технический стек

| Слой | Технология |
|---|---|
| Фреймворк | React 18 + TypeScript |
| Сборка | Vite 8 |
| Стили | Tailwind CSS v4 + CSS Custom Properties |
| Анимации | Framer Motion (AnimatePresence, layout animations) |
| Состояние | Zustand + persist middleware (localStorage) |
| Роутинг | React Router v6 (BrowserRouter) |
| Аудио | Нативный Web Audio API (HTMLAudioElement) |
| Иконки | Кастомные SVG (стиль Untitled UI / Lucide) |
| Шрифт | Manrope (Google Fonts) |
| PWA | vite-plugin-pwa (Service Worker + манифест) |
| Хостинг | Vercel (автодеплой по git push) |

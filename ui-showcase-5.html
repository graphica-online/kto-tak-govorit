Сравнение концептов

Каждый — принципиально другой подход к расположению элементов

CONCEPT 01

Photo + Sidebar

Фото 70% экрана, вся информация и управление — в сайдбаре слева. Как DeepSeek, ChatGPT.
✓ Удобно за ноутбуком (сценарий B)
✓ Всё видно сразу без ховеров
✓ Сайдбар скроллится на мобиле
– Фото не на весь экран
CONCEPT 02

Fullscreen + Bottom Bar

Фото 100% экрана, управление и текст — оверлей внизу. Как Apple TV, Netflix.
✓ Максимально красивое фото
✓ Кинематографично
– Текст может плохо читаться
– На мобиле нижний бар закрывает фото
CONCEPT 03

Fullscreen + Glass Panel

Фото 100%, стеклянная плавающая панель справа. Как Figma, Linear.
✓ Эффектно, современно
✓ Панель не мешает фото
✓ Легко скрыть панель для immersive
– Backdrop-filter тяжёл на слабых устройствах
CONCEPT 04

Split 50/50 Dashboard

Фото слева, dashboard с информацией справа. Как Arena.ai, Notion.
✓ Самый «dashboard» из всех
✓ Отлично для портфолио
✓ Удобно с клавиатуры
– Фото только 50%
CONCEPT 05

Fullscreen + Minimal HUD

Фото 100%, минимум UI поверх. Максимум immersive. Как Instagram Stories.
✓ Максимальное погружение
✓ Идеально для малышей
– Мало информации на экране
– Нужен ховер/тап для управления
💡 Мои рекомендации:

Для десктопа: Concept 1 (Sidebar) или Concept 4 (Split) — оба дают dashboard-ощущение, управление видно, фото большое.

Для мобильных: Concept 2 (Bottom bar) или Concept 5 (HUD) — фото на весь экран, свайпы, минимум UI.

Идеальный гибрид: На десктопе — Concept 1 (Sidebar), на мобиле автоматически — Concept 2 (Bottom bar). Один компонент, два layout через CSS media queries. Это даст лучший UX на обоих устройствах.
